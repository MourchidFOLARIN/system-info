# System Info

Un outil développé en Python pour afficher les informations essentielles d'un ordinateur.

## Fonctionnalités

- Informations générales sur le système
- Informations sur le processeur
- Informations sur la mémoire RAM
- Informations sur le stockage
- Informations réseau
- Date et heure

## Technologies utilisées

- Python 3
- Psutil
- Socket
- Platform

## Prérequis

- Python 3
- Git
- pip
- venv
